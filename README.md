# Bühnen-Countdown

Countdown-Timer für Vorträge im Stil des TED-Timers – aber einstellbar bis **120 Minuten** statt nur 18.

- Grün während der Zeit läuft, Gelb und Rot ab einstellbaren Restzeiten
- Nach 0:00 zählt der Timer blinkend die Überziehung hoch, optional mit Gong
- ±1 Minute während des Vortrags, Vollbild, Bildschirm bleibt wach
- Tastatur: Leertaste Start/Pause · R Reset · ↑/↓ ±1 min · F Vollbild

Die ganze App ist eine einzelne Datei: `index.html`. Einfach im Browser öffnen oder über GitHub Pages bereitstellen.
